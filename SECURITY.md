# Sicherheitsmeldungen und sensible Daten

Bitte veröffentliche in GitHub Issues, Pull Requests und Diskussionen keine DICOM-Dateien, Patientendaten, Bereinigungsberichte, Zugangsdaten oder Screenshots mit solchen Angaben. Verwende für reproduzierbare Fehler ausschließlich selbst erzeugte synthetische Beispieldateien.

Wenn GitHub für dieses Repository private Sicherheitsmeldungen anbietet, nutze **Security → Report a vulnerability**. Sende dabei zunächst nur eine Beschreibung und Schritte mit synthetischen Daten. Falls kein privater Meldeweg eingerichtet ist, eröffne kein öffentliches Issue mit sensiblen Details; bitte den Maintainer zuerst um einen privaten Kontaktweg.

Eine vom Cleaner erzeugte Datei ist nicht automatisch zur Veröffentlichung freigegeben. OCR kann Text übersehen; Bildpixel, Gesichter, Freitext und besondere DICOM-Objekte müssen gesondert kontrolliert werden.
